# 🦋 My Little Universe

A cozy, Pinterest-inspired personal website that tells my story beyond a traditional portfolio. Instead of simply showcasing projects, this website captures my journey, inspirations, dreams, favorite moments, and the little things that make me who I am.

## ✨ Features

- Beautiful Hero Section
- Interactive Journey Timeline
- My World Section
- Technology & People Section
- Camera Roll Gallery
- Dream Board
- Random Thoughts
- Personal Letter
- Responsive Design
- Smooth Animations
- Scroll Progress Bar
- Back to Top Button

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 🎨 Design Inspiration

The website follows a warm, soft, and Pinterest-inspired aesthetic featuring:

- Sage Green
- Cream & Beige tones
- Minimal layouts
- Polaroid-style gallery
- Glassmorphism
- Smooth hover animations

## 💡 Purpose

This project was created to explore creative web design while expressing my personality beyond a traditional portfolio. It reflects my interests, journey, aspirations, and the balance between technology and human connection.
